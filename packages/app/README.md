# `@executioncontrolprotocol/app`

Visual App: execution graph, validation panel, live run overlay, and run history. Served by the
host at `/app/`.

**Entrypoints:** `src/index.ts` (library helpers), `dist/web/` (Vite bundle)

Open with `ecp app <path>`. Playwright acceptance: `packages/app/test/e2e/a8-app.spec.ts`.
